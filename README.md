# Unsupervised Semantic Segmentation of Histology (H&E) Images

This repo contains my contributions to a larger project where various statistical and deep learning segmentation methods were benchmarked in terms of their application to histology images. 

I built a pipeline that takes the segmentation mask generated by the model, and computes statistics i.e., F1 score, confusion matrix, for model comparison. 

| File | Description |
| ---- | ----------- |
| metrics.py | Functions that compute confusion matrix, TP/TN/FP/FN, precision, recall, F1 score, and accuracy. |
| pipeline.py | Pipeline that uses functions from metrics.py to compute and save statistics given all segmentation masks generated by a model. |
| pyimseg_segmentation_algorithm.py | Adapted the [pyImSeg algorithm](https://github.com/Borda/pyImSegm) to process a directory of sample images and output class labels at each (x,y) coordinate. |
| environment.yml | Packages required to make the conda environment for this project. |

### To run the metrics pipeline
```
pipeline.py -pred <path/to/predicted/masks> -truth <path/to/true/masks> -out <path/where/outputs/will/be/saved>
```
